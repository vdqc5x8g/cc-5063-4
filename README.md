# 曲面拼接工作台

参数曲面接边与连续性求解工具。选择两片曲面的对应边界，建立参数方向与对应关系，
求解满足位置连续 / 切平面连续 / 参数连续的控制量，并以解析曲面直接验算接缝误差。

## 快速开始

```bash
npm install
npm run dev        # 浏览器打开 http://localhost:5173/ （默认进入 locklab 冲突/让步实验）
```

> 需要 Node.js 18+。若 5173 端口被占用，`vite.config.ts` 设了 `strictPort: true`，
> 请先释放该端口或自行修改端口配置。启动后页面会自动求解并给出冲突定位与锁边预演。

完整说明（图形入口、连续性条件、对应方式、固定侧与约束冲突、导出、命令行、测试）
见 **[docs/README.md](docs/README.md)**。

## 要点

- **图形界面为主入口**：所有拼接、路线对比、冲突定位、锁边让步与副本复检都接到真实求解核心并在 Three.js 视窗标注。
- **两条连续性路线实测取舍**：对比“参数导数一致 C1”与“共切面连续 G1”，据代码复算结果给推荐，而非预设必须 C1。
- **不可兼得位置自动标出**：受阻 / 不可兼得 / 代价过高聚类，点击列表即在三维中定位聚焦。
- **选锁定边预演松开效果**：两次真实求解 + 解析复检，量化让步控制点位移与被消除 / 缓解的误差折线段，可在副本应用后重新量测、保留或还原。
- **G1 与 C1 严格区分**：速度不同但切面相同时，G1 近零代价保留速度比，C1 以可测形变换取速度比为 1。
- **按几何对应**（弧长 / 参数 + 方向）匹配边界，不按控制点索引比较；支持反向参数、不同次数、不同节点密度、弯曲接边。
- **固定侧不变、边界锁、内部形态保持**；无法同时满足时返回**约束冲突**，不擅自移动整片模型。
- **误差由解析曲面求值**（位置间隙、法线夹角、切平面偏差、速度比、C1 失配），
  不以焊接显示网格、控制点重合或平均法线冒充切向连续。视窗提供**真实接缝线与反射线检查**，可导出真实解析曲面。

## 实验与质量门禁

```bash
npm run experiments         # 重新求解全部实验并生成证据 JSON + 结论文档表格
npm run experiments:check   # 证据/文档过期即失败（防伪报）
npm test                    # 24 项：内核 15 + 路线实验室 6 + 证据新鲜度 3
npm run build               # tsc --noEmit + vite 打包
npm run cli -- --all        # 七场景 × G0/G1/C1 端到端矩阵
```

- 连续性模型取舍的**待验假设**单列：**[docs/continuity-model-assumptions.md](docs/continuity-model-assumptions.md)**
