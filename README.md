# 曲面拼接工作台

参数曲面接边与连续性求解工具。选择两片曲面的对应边界，建立参数方向与对应关系，
求解满足位置连续 / 切平面连续 / 参数连续的控制量，并以解析曲面直接验算接缝误差。

## 快速开始

```bash
npm install
npm run dev        # 浏览器打开 http://localhost:5173/
```

完整说明（图形入口、连续性条件、对应方式、固定侧与约束冲突、导出、命令行、测试）
见 **[docs/README.md](docs/README.md)**。

## 要点

- **图形界面为主入口**，命令行仅辅助批量校验与导出。
- **G1（切平面连续）与 C1（参数连续）严格区分**：速度不同但切面相同时，两者给出不同调整。
- **按几何对应**（弧长 / 参数 + 方向）匹配边界，不按控制点索引比较；支持方向反转、不同节点密度、弯曲接边。
- **固定侧不变、内部形态保持**；无法同时满足时返回**约束冲突**，不擅自移动整片模型。
- **误差由解析曲面求值**（位置间隙、法线夹角、切平面偏差、速度比、C1 失配），
  不以焊接显示网格或平均法线冒充连续。视窗提供**反射线检查**，可导出真实解析曲面。
