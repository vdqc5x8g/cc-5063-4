# 曲面拼接工作台 · Surface Stitch Studio

参数曲面（张量积 B 样条）的接边与连续性求解工具。选择两片曲面的对应边界，建立
参数方向与对应关系，求解满足 **位置连续(G0) / 切平面连续(G1) / 参数连续(C1)** 的
控制量，并以**解析求值**（而非显示网格）直接验算接缝误差。结果在视窗中以反射线条纹
呈现，并可导出两片独立的真实解析曲面。

---

## 图形入口（主界面）

> 图形界面是本工具的主要入口；命令行仅用于批量校验与导出。

```bash
npm install
npm run dev          # 打开 http://localhost:5173/
```

浏览器中即出现「曲面拼接工作台」：

- **左栏**：测试场景、对应边界、方向、对应方式、连续性条件、固定侧、变形行数、
  内部形态保持刚度、近缝优先权重、约束采样数、视窗显示开关。
- **中间视窗**：两片曲面 + 反射线条纹 + 接缝 + 间隙梳；左键旋转、滚轮缩放、
  右键平移；点击曲面可选中最近的边界作为接边；「聚焦接缝」拉近检查。
- **右栏**：连接结果、解析连续误差指标、沿接缝误差分布图、导出按钮。

### 界面工作流

1. 在左栏「选择测试场景」挑一个，或直接在视窗里点击某条边界选中接边。
2. 核对 **A 侧接边 / B 侧接边** 与 **边界方向**（同向 / 反向）。工具默认按两端点的
   几何距离自动判定方向；可手动覆盖。
3. 选择 **对应方式**：弧长对应（按几何长度，推荐）或参数对应（按参数值）。
4. 选择 **连续性**：G0 / G1 / C1；选择 **固定侧**（该片完全不动）。
5. 设定 **可变形控制行数** 与 **形态保持刚度**后，点击「求解拼接」。
6. 打开「反射线条纹」，按「聚焦接缝」观察条纹是否跨接缝连续。
7. 在「接缝连续误差」区核对位置间隙、切平面偏差、法线夹角、参数速度比、C1 失配。
8. 在「导出真实曲面」区导出 JSON / OBJ / CSV / TXT / PNG。

### 冲突定位与锁定边让步预演（连续性模型取舍）

启动后默认进入 `locklab` 场景并自动完成一次求解、一次 G1/C1 路线对比和 `side1` 预演：

1. 左栏「4. 边界锁与连续性取舍」勾选 / 取消 `opposite / side0 / side1`，设定让步预算，
   点击 **「实测 G1 / C1 路线对比」**。运行中按钮禁用并显示“计算中”，完成后给出耗时。
2. 右栏「连续性模型实测对比」给出**据实测的推荐（G1 或 C1）与原因**、两路线的
   变量 / 约束秩 / 零空间 / 最大位移，以及冲突段列表：红=连接受阻、橙=不可兼得、黄=代价过高。
   **点击任一冲突行，三维视窗会用球标 + 定位环标出并把相机聚焦到该 ξ 位置。**
3. 右栏「锁定边 · 松开预演与副本复检」点选一根边：已锁定边会真实执行两次求解
   （保持锁定 vs 仅松开该边），显示最大让步控制点位移、该边是否参与约束、间隙/角度/C1
   的“锁→松”、超差占比，以及被 **消除 / 缓解 / 显著压低** 的 ξ 区间。
   视窗中洋红管道+极点是锁定边，洋红箭头是让步位移（可勾选“视觉放大 ×8”，面板读数仍为真实位移），
   绿 / 橙 / 蓝管道分别是消除 / 缓解 / 显著压低段。
4. 点 **「在副本上应用松开并重新量测」**：视窗与指标立即换成松开后的真实求解结果，
   顶部出现试验条；可选 **「保留并设为新基准」** 或 **「还原副本」**。

> 这套界面动作全部接到 `src/core/route-lab.ts` 的真实两次求解与解析复检，不是预制动画。
> 量化结论与复算方式见 [`surface-seam-experiments.md`](./surface-seam-experiments.md)，
> 尚待一般化验证的假设见 [`continuity-model-assumptions.md`](./continuity-model-assumptions.md)。

## 连续性条件与两种做法

设固定侧横向（指向片内）导数为 `dA`，自由侧横向导数 `dB`，沿边导数 `sA / sB`，
固定侧法线 `nA`。

| 条件 | 约束 | 含义 |
|------|------|------|
| **G0** | `P_B = P_A` | 位置重合，切平面可有折角 |
| **G1** | `nA · dB = 0`（并保持 G0） | 两片共享切平面；**参数速度可以不同** |
| **C1** | `dB = -dA` 且 `sB = ±sA`（并保持 G0） | 参数导数相等；速度比必为 1 |

「保持参数导数相等」(C1) 与「允许参数变速只约束共同切平面」(G1) 是两种不同办法。
当两片在接缝处**速度不同却有相同切面**时（见场景 `speed`），两者给出不同调整：

- **G1**：切平面已连续，控制点**完全不动**，速度比维持约 2.0。
- **C1**：横向导数被强制相等，近缝控制行被压缩，速度比变为 1.0，形状发生改变。

界面「反射线条纹」用于验收：G1 后条纹跨接缝连续；G0 后条纹在接缝处折角/跳变。
**注意**：反射线是诊断视图，连续性判定以右栏直接验算的导数为准。

## 几何对应（不按控制点索引比较）

- 边界方向可相反（`direction = -1`）。对应时沿边界按归一化位置配对，
  **绝不按相同索引比较控制点**。
- 弧长对应：把 A、B 两边界各自归一化弧长后按同一弧长比例配对；节点密度不同的两片
  （场景 `density`）也必须用弧长对应才不会错配。
- 参数对应：直接按参数值配对；当节点分布不同时会产生几何错配，可用于对照说明。
- 曲面法向朝向：翻转参数方向会翻转 `dU×dV`。界面的「翻转 A/B 法向」声明片体朝向；
  若两片朝向相反，求解会返回「朝向相反」的约束冲突而不是靠移动控制点掩盖。

## 求解与「固定侧 / 内部形态」

- **固定侧**：`fixed = A` 时 B 可动，反之亦然；固定侧的控制点绝不改动（测试断言逐点相等）。
- **可变形控制行数**：只允许接缝向内若干行控制点移动；更内层控制点保持原值。
- **内部形态保持刚度 / 近缝优先权重**：正则项把自由控制点拉回原位，越远离接缝越强，
  用于保留用户指定的内部形态偏好。
- 求解为加权最小二乘：位置行权重远高于切向行，避免用位置间隙去交换切向条件。
- **无法同时满足时返回「约束冲突」**（`status: conflict`）并给出原因，**不会擅自移动整片模型**。
  例如场景 `conflict`：只允许 1 行可动且固定 B 时，切平面偏差达 59.65°，界面右侧
  显示冲突与建议（增大变形行数 / 切换固定侧 / 放宽形态偏好）。

## 验收与误差（全部由解析曲面计算）

右栏指标与导出报告均通过对**解析 B 样条曲面**直接求值得到，而非对显示网格求平均：

- 位置间隙：对应点间距离的最大值与均方根。
- 法线夹角：两片解析法线的最小夹角（0–90°，与朝向无关）。
- 切平面偏差：自由侧横向导数偏离固定侧切平面的角度（G1 应为 ~0）。
- 参数速度比 `|dB|/|dA|` 与 C1 失配 `|dA+dB|/|dA|`（C1 应为 ~0、速度比 ~1）。
- 沿边切向偏差（计入方向反转）。

> **不使用**「焊接显示网格边缘」来掩盖裂缝，也**不把接缝处法线平均**当作切向连续的证明。
> 导数关系在 `measureSeam` 与独立有限差分核对中直接验算。

### 测试场景（覆盖方向反转 / 不同节点密度 / 弯曲边界）

| id | 内容 |
|----|------|
| `speed` | 同切平面、不同参数速度 → 区分 G1 与 C1 |
| `tilt` | 倾斜邻片 + 非均匀节点 → 初始有间隙与折角 |
| `reversed` | 边界走向相反（方向 -1，朝向翻转） |
| `density` | 两片节点密度不同 → 弧长 vs 参数对应差异 |
| `curved` | 弯曲（空间曲线）接边 |
| `conflict` | 变形行数不足 / 固定侧受限 → 约束冲突 |
| `locklab` | 端边被邻面顶偏并锁定 → 冲突定位 + 松边消除段/让步预演（默认启动场景） |

## 导出真实曲面

- **JSON 解析曲面**：两片各自的次数、控制网、节点向量、朝向；附接缝误差。可完整重建解析曲面。
- **OBJ 曲面 + 接缝**：两片独立网格（未焊合）+ 接缝折线；文件头写入接缝间隙与切平面偏差。
- **CSV 接缝误差**：沿接缝逐点误差表，便于独立核对。
- **TXT 报告**：完整文字报告。
- **PNG 截图**：当前视窗（可含反射线检查结果）。

接缝折线仅为显示/参考；导出保留两片独立解析曲面，**不会**以焊合网格冒充已闭合的解析曲面。

## 命令行（辅助）

```bash
npm run cli -- --list
npm run cli -- --all                     # 七场景 × G0/G1/C1 端到端矩阵
npm run cli -- --scene locklab --continuity G1
npm run cli -- --scene tilt --continuity G1 --fixed A --rows 3
npm run cli -- --scene speed --continuity C1 --correspondence parameter --json
npm run cli -- --scene tilt --out ./out      # 写出 JSON/OBJ/CSV/TXT
```

`--all` 只要 21 个组合都跑出报告即视为旧样例运行到底（设计内的 conflict 也是正常报告，
只有抛异常才返回非零）。单场景退出码：`0` 成功，`2` 约束冲突，`3` 数值退化；
命令行输出与界面一致，均由同一解析内核计算。

## 开发与测试

```bash
npm test        # vitest：核心 15 项 + 路线实验室 + 证据/文档新鲜度（共 24 项）
npm run experiments:check
npm run build   # tsc --noEmit && vite build
npm run dev     # 图形界面 http://localhost:5173/ （默认 locklab）
```

核心结构：

- `src/core/bspline.ts` — B 样条基底与导数（The NURBS Book A2.2/A2.3）。
- `src/core/surface.ts` — 张量积曲面求值、法线、朝向。
- `src/core/seam.ts` — 边界框架、对应（弧长/参数、方向）、求导系数。
- `src/core/solver.ts` — 加权最小二乘约束求解 + 边界锁 + DOF 秩/零空间 + 冲突判定。
- `src/core/continuity.ts` — 解析接缝误差量测。
- `src/core/route-lab.ts` — G1/C1 双路线对比、不可兼得聚类、锁边松开反事实预演。
- `src/core/prototypes.ts` — 速度比/速度鼓包/异次实验原型。
- `src/core/shape-cost.ts` — 控制点位移、曲面偏差、二阶形变能。
- `src/core/exporters.ts` — JSON/OBJ/CSV/TXT 导出。
- `src/experiments/run.ts`、`src/experiments/markdown.ts` — 证据引擎与文档表格渲染。
- `scripts/experiments.ts` — 证据/文档生成与 `--check` 新鲜度门禁。
- `src/ui/` — 视窗（Three.js，反射条纹 + 冲突/让步标注）、状态 store、面板。
- `src/cli.ts` — 辅助命令行（含 `--all` 矩阵）。
- `src/tests/` — 核心套件、路线实验室测试、实验证据新鲜度测试。
